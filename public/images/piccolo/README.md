# Piccolo Restaurant Images

This directory contains all images specific to the Piccolo restaurant location.

## Required Images

### Homepage Images
- `HeroLatestImage.jpeg` - Hero section background
- `Interior.webp` - Restaurant interior photo
- `Pasta.webp` - Pasta dish photo (for experience section)
- `Nos Pasta.webp` - Pasta menu card image
- `Pizzas Napolitaines.webp` - Pizza menu card image
- `Deserts Italiens.webp` - Desserts menu card image
- `Secrets de Saveur.webp` - Secrets section image
- `restaurant-evening.webp` - Hours section background
- `certificate.webp` - Halal certificate image
- `menu-bg.webp` - Menu page background

### Menu Item Images (`menu/menu-item/`)
Add individual menu item photos here. These will be used in the menu display.

### Add-ons Images (`menu/add-ons/`)
Add photos for menu add-ons/supplements here.

### Testimonial Images (`testimonial/`)
Add customer testimonial profile photos here.

## Note
Until these images are uploaded, the site will show broken image placeholders or fallback to default images. You can copy images from `/public/images/` and customize them for Piccolo, or upload entirely new photos.
